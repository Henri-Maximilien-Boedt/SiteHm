# Awesome Design MD

A curated reference library of brand design systems. Each brand lives under
`references/<brand>/DESIGN.md` and documents that brand's real visual language —
palette, typography, spacing scale, radii, shadows, motion, and component patterns.

## How to use

1. Identify the brand(s) the user names, or that best match the vibe they want.
2. Read `references/<brand>/DESIGN.md` for the full spec. Read `README.md` in the
   same folder for a quick summary.
3. Apply those conventions to the work. Cite which brand you drew from so the user
   can swap direction. Do not blindly copy trademarked logos or brand names into a
   user's own product — use these as design-language references, not for passing
   off a product as that brand.

When the user doesn't name a brand, suggest 2-3 whose aesthetic fits their brief
(e.g. "clean dev-tool" → linear.app, vercel, raycast; "luxury/automotive" →
ferrari, bugatti, bmw-m; "playful consumer" → airbnb, notion, spotify).
